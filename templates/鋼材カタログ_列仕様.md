# 鋼材カタログ CSV 列仕様

`鋼材カタログ_取込テンプレート.csv` の各列の意味。
アプリの「CSV書き出し」もこれと同じ列構成で出力するため、書き出し → Excelで編集 → 取込 の往復ができる。

- 文字コード：UTF-8(BOM付き) / Shift-JIS のどちらでも取込可（自動判定）。書き出しは UTF-8(BOM付き)
- 改行：CRLF
- **重複判定キー：種類 ＋ 材質 ＋ サイズ ＋ スケジュール**
  この4つが同じ行は同一品目とみなし、新規登録ではなく更新になる（二重登録の防止）

---

## 列一覧

| # | 列名 | 必須 | 内容 | 例 |
|---|---|---|---|---|
| 1 | 品目コード | | 見積Excelの単価マスターと突き合わせるための参照用コード。**重複判定には使わない**（判定は下の4項目）。空欄可 | `PIPE-SUS304-20A-SCH10` |
| 2 | 種類 | ★ | 配管／フランジ／アングル／溶接継手／ねじ込み継手／形鋼／パッキン／ボルト | `配管` |
| 3 | 材質区分 | | SS／SUS／アルミ／その他。絞り込みの大分類 | `SUS` |
| 4 | 材質 | ★ | 規格名。段階絞り込みの2段目に出る | `SUS304` |
| 5 | サイズ | ★ | 配管は呼び径、鋼材は寸法表記。段階絞り込みの3段目に出る | `20A` / `30×30×3` |
| 6 | スケジュール | | 配管のみ。Sch10／Sch40／白／黒 など。配管以外は空欄 | `Sch10` |
| 7 | 品名 | | 空欄なら生成ルールで自動生成（下記）。手で決めたいときだけ書く | `SUS304TP 20A Sch10` |
| 8 | 規格 | | JIS番号。品目詳細と一覧の副題に出る | `JIS G3459 (SUS304TP)` |
| 9 | 外径mm | | 配管の外径（数値） | `27.2` |
| 10 | 肉厚mm | | 配管の肉厚（数値） | `2.1` |
| 11 | 厚みmm | | 鋼材の厚み（数値） | `3` |
| 12 | 幅mm | | 鋼材の幅（数値） | `30` |
| 13 | 高さmm | | 鋼材のもう一辺（山形鋼・溝形鋼・H形鋼）（数値） | `30` |
| 14 | 長さmm | | 定尺長さ（数値） | `6000` |
| 15 | 呼び圧力 | | フランジ用。5K／10K／16K／20K | `10K` |
| 16 | 形式 | | フランジ用。FF／RF／SOP／BL など | `10K RF SOP` |
| 17 | 寸法表示 | | 詳細画面に出す寸法テキスト。空欄なら 9〜14列から自動生成 | `外径27.2mm × 肉厚2.1mm` |
| 18 | 単位重量 | | 数値のみ。kg単価から金額を出すのに使う | `1.26` |
| 19 | 重量単位 | | `kg/m`／`kg/枚`／`kg/個`。空欄なら kg/m 扱い | `kg/m` |
| 20 | 単位 | ★ | 本／枚／個／kg | `本` |
| 21 | 参考単価 | | 円・整数（数値） | `1550` |
| 22 | 仕入先 | | | `丸信商会` |
| 23 | 適正在庫 | | この数を下回ると「不足」バッジ＋発注対象（数値） | `8` |
| 24 | 並び順 | | 同じ階層内での表示順。空欄ならサイズの数値順 | `20` |
| 25 | 在庫に登録 | | `1`／`はい` で在庫一覧に出す。空欄・`0`・`いいえ` はカタログのみ | `1` |
| 26 | 松前工場 | | 在庫数（数値）。**空欄なら現在の在庫数を変更しない** | `12` |
| 27 | 伊予工場 | | 同上 | `3` |
| 28 | 東方工場 | | 同上 | `5` |
| 29 | 保管場所 | | 鋼材側の置き場メモ（消耗品の保管場所マスタとは別物） | `資材置場 東` |

★＝必須。空欄だとその行はエラーになり、プレビューで行番号と理由が表示される。

---

## 在庫数列（26〜28）の扱い

- **空欄 → 現在の在庫数はそのまま**（カタログ情報だけを更新したいときは空欄にする）
- **数値 → その値に上書き**。差分は履歴に「CSV取込」として記録される（誰が・いつ・どの拠点）
- 25列目「在庫に登録」が空欄でも、26〜28のいずれかに数値があれば在庫に登録される

## 品名の自動生成ルール（7列目が空欄のとき）

| 種類 | ルール | 例 |
|---|---|---|
| 配管 | 材質 + サイズ + スケジュール（SUS304 は `SUS304TP` に置換） | `SUS304TP 20A Sch10` / `SGP 20A 白` |
| アングル | 材質 + `アングル` + サイズ | `SUSアングル 30×30×3` |
| 形鋼（平鋼） | 材質 + `平鋼` + サイズ | `SS平鋼 25×3` |
| その他 | 材質 + 種類 + サイズ | `SUS304 フランジ 20A` |
